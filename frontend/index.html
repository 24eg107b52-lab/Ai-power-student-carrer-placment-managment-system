🎯 Key Objectives & Project Scope
Academic Specification
  • ✔
    Centralize Data: Unified data layer connecting student profiles, academic CGPA, backlogs, certifications, and live placement drives.
  • ✔
    Dynamic Employability Scoring: Machine learning multi-criteria evaluation model analyzing academics (25%), technical depth (30%), aptitude (20%), and interviews (15%).
  • ✔
    Automated NLP Matching: TF-IDF vectorization and Cosine Similarity to objectively score and rank resume suitability against employer job descriptions.
  • ✔
    AI Mock Interview Simulator: Evaluates verbal spoken responses and technical answers with instant feedback, keyword coverage, and articulation scoring.
  • ✔
    Placement Analytics Dashboard: Live institutional statistics, department-wise placement breakdown, and trend forecasting for placement officers.
